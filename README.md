# Portfolio Website

Minimal portfolio website scaffold.

How to run locally:

- Open `index.html` in a browser.
- Or run a simple static server, e.g. with Python:

```
python -m http.server 8000
```

Files:

- index.html
- css/style.css
- js/script.js
- images/
